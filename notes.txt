          [()] -> Data flows back and forth between component and UI
          () —> Listens to UI events and calls component methods (UI → Component)
          [] —> Binds component property to HTML element property/attribute (Component → UI)
          {{}} -> Displays component data in the template (Component → UI, display only)
          {} — Control flow :
            Used with Angular control flow directives like @if, @for, @switch, @else
            The {} encloses the conditional block, not the condition itself
            The condition goes in (), the block content goes in {}
